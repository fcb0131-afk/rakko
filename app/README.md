# 朝の15分

毎朝15分だけ開く、note×X×AI副業のダッシュボード。

---

## スマホで使えるようにする（初回だけ）

1. ブラウザで https://app.netlify.com/drop を開く
2. この `app` フォルダを、そのままページの中にドラッグ＆ドロップする
3. 数秒でURLが発行される（`https://〇〇〇.netlify.app` のような形）
4. そのURLをスマホで開く
5. **ホーム画面に追加**する
   - iPhone … 共有ボタン → 「ホーム画面に追加」
   - Android … メニュー → 「ホーム画面に追加」

これで、毎朝ホーム画面から1タップで開けるようになります。

> URLを他人に教えなければ、事実上あなただけのアプリです。
> 記録はあなたの端末の中だけに保存され、どこにも送信されません。

### PCで中身を確認したいとき

`index.html` をダブルクリックすればブラウザで開きます。
（オフライン動作の確認だけは、下のローカルサーバ経由でないとできません）

```
python -m http.server 8123 --directory app
```

## 中身を書き換えたいとき

**`roadmap.js` だけを触ってください。** 他のファイルは触らなくて大丈夫です。

タスクの文言、説明文、ChatGPTに貼るプロンプト、所要時間は、すべてこのファイルの中にあります。

```js
{
  id: "genre-seed",        // ← ここは変えない（進捗の記録に使っています）
  title: "…",              // 画面に大きく出る「今日やること」
  desc:  "…",              // その下のやわらかい補足
  minutes: 15,             // 目安の時間
  prompt: "…",             // ChatGPTにそのまま貼れる文章（不要なら省略）
  optional: true           // true にすると、遅れたとき「あとで」に送れる対象になる
}
```

書き換えたら、もう一度 Netlify Drop にフォルダをドロップすれば反映されます。

---

## 使い方のルール

- **毎朝、出てきた1個だけをやる。** 何をやるか考える必要はありません
- **土日は休み。** それでも進めたくなったら、いつでも次の1個を引けます
- **できない日があっても、数字は減りません。** 連続記録は意図的に表示していません
- **遅れたら、アプリが戻し方を出します。** 選ぶだけでペースが引き直されます

---

## バックアップ

記録は端末のブラウザの中だけに保存されています。**ブラウザのデータを消すと失われます。**

画面下の「DATA・バックアップ」から、ときどき **書き出す** を押してファイルを保存しておいてください。
機種変更のときは、新しい端末で **読み込む** から復元できます。

## ファイルの役割

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目 |
| `roadmap.js` | **やることの中身（ここだけ触ればOK）** |

| `manifest.json` / `sw.js` | ホーム画面追加とオフライン動作 |
