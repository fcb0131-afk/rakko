# 本編の要点（『2億円を売り上げたプロが教える NOTE×AI』）

このファイルは、`らっこ本のPDF.pdf`（177ページ、リポジトリには含めていない）から書き起こした要点です。**すべての判断のゆるがない土台**として扱う。特典素材と食い違う場合は、原則こちらを優先する（ただし本人の「人を傷つけない・押し付けない」という軸は、本編よりさらに優先する）。

## ジャンル選定

### やってはいけないこと
- 自分の「好き」「得意」という理由**だけ**でジャンルを決めない（自己完結型の発信になり、フォロワーが増えない）
- 「誰に、どんな価値を提供できるか」が曖昧なまま発信を始めない

### 稼げるジャンルを見極める3つの要素
1. **市場の大きさ**：関連キーワードで検索し、発信者のフォロワー数を見る。ただし市場規模だけで判断しない（悩みの深さ・緊急度が高ければ市場が小さくても大きな収益を狙える）
2. **悩みの深さ**：お金を払ってでも解決したいほど切実か
3. **悩みの緊急度**：「今すぐ解決したい」ものか（将来の予防＝サプリメントより、今すぐ解決したい＝薬の方が売れる）

「市場の大きさ」×「悩みの深さ」×「悩みの緊急度」の掛け算で、そのジャンルが収益化できるかがほぼ決まる。

### HARMの法則（人がお金を払ってでも解決したい4大カテゴリー）
- **H (Health)** — 健康・美容。「痩せたい」「コンプレックスを解消したい」
- **A (Ambition)** — 野心・夢・キャリア。「副業で成功したい」「英語を習得したい」
- **R (Relation)** — 人間関係。「恋人が欲しい」「上司との関係を改善したい」
- **M (Money)** — お金。「もっと稼ぎたい」「老後の資金が心配」

### らっこ式・三大欲求
1. 繁殖欲求（恋愛・結婚・美容・ダイエットなど、魅力的だと思われたい）
2. 承認欲求（SNSで注目されたい、尊敬されたい）
3. 金銭欲求（稼ぎたい、資産を増やしたい）

「稼ぐ系」ジャンル（お金を稼ぐ方法を教える）は、自分に実績がないと信頼を得にくいので、実績のない初心者にはあまり推奨されない。

### 完璧主義を捨てる
- 市場調査だけで100点の答えは出ない
- **60〜70点の確信度でよいので、まず1ヶ月集中して発信してみる**。反応が悪ければ軌道修正すればいい
- リサーチに時間をかけすぎて動けなくなるのが最大の失敗パターン

## X運用

### 運用前の必須設定
- 2要素認証（またはパスキー）
- 「見つけやすさと連絡先」をすべてオフ（身バレ防止）
- 誕生日の公開範囲を「自分のみ」（任意）
- センシティブ設定を解除し、表示制限を外す

### アカウント設計
- 名前：専門性（一目で「◯◯の人」とわかる）・記憶性（5文字以内推奨）・信頼性
- アイコン：視認性（埋もれない）・権威性
- プロフィール：誰のどんな悩みを解決するかを明記

### コンセプト・キャラクター
- フォロワー数ではなく「売上」につながる軸を定める
- 発信テーマは具体的に絞り込む（「ダイエット」ではなく「カロリー制限ダイエット」）
- 目的は「note で稼ぐこと」であり「フォロワーを増やすこと」自体ではない

### 競合リサーチ
- 競合がほとんどいない「ニッチすぎる市場」は儲からない可能性が高い
- 同ジャンルで note 累計100万円以上稼いでいる競合を3人以上見つける（目安計算式：スキの数×記事価格×1.5）
- 相互フォロー・相互リポストで伸びているアカウントは参考から除外する

### NG運用10選（要点）
- 相互フォロー頼みのフォロワー集め
- 誰にでも送れる定型文リプライ
- やみくもな大量いいね
- ジャンル違いの投稿で専門性がブレる
- リサーチを怠る

### 良い投稿の型
- 投稿の7〜8割は読者のための有益な情報
- 抽象論ではなく、読者が「自分にもできそう」と思える具体性
- 1日3〜5ポスト（最低1ポスト）を継続
- 固定ポストにプロフィール直下で一番見てほしい投稿を置く

## note記事作成

- 有料エリアから執筆を始める（無料部分は宣伝なので後回しでよい）
- 同ジャンルで売れている note を最低ひとつ購入して読む
- 目次を先に作る。目次を読んだだけで「悩みが解決しそう」と感じられる構成に
- 文字数は同ジャンルで一番売れている記事より多く
- 無料エリアの黄金テンプレート：冒頭の引きつけ→悩みと解決策の提示→未来の提示→自己紹介→執筆のきっかけ→特典紹介→オススメする人/しない人→限定性・希少性→価格の妥当性→有料エリアへの寸止め
- 書きあげてから最低1日置いて客観的に見直す
- スマホでの見え方を必ず確認する

## AI活用の心構え

- AIが生成した情報は鵜呑みにせず、必ず自分でファクトチェックする
- AIを「超優秀なアシスタント」として、二人三脚で仕事を進める
- 一発で完璧な答えを求めず、「より良い出力をするために、私に聞いたほうがいいことがあれば質問してください」と対話しながら改善する

## 販売戦略

### 9つの販売テクニック（誠実に使える範囲で）
1. 引用特典（感想をポストしてくれた方限定の特典）
2. 希少性の原理（〇部限定・〇日間限定）
3. カリギュラ効果（あえて「本気の人以外は買わないで」と伝える）
4. デメリット訴求（向いていない人を正直に伝える）
5. リフレーミング（価格の見方を変える）
6. アフターフォロー
7. 損失回避バイアス（先行価格の期限を伝える）
8. ベネフィット訴求（機能でなく生活がどう変わるか）
9. 無料モニター企画

**すべてを支える大原則**：テクニックに頼るだけでなく、価格以上の価値がある「魂のこもった記事」であること。

### 発売ロードマップ
発売1ヶ月前（需要確認）→2〜3週間前（進捗報告）→1〜2週間前（モニター募集）→1週間前〜直前（情報小出し）→発売当日（スタートダッシュ・実況中継・口コミ活用）

## 補足：Google AI × noteの5ステップ（プレゼント2）
出典：`らっこ_3_Google AI/プレゼント2：note記事作成の5ステップ.pdf`

1. **ターゲット設定** — 基本属性・家庭環境・仕事/社会・内面/未来に加え、「建前と本音」の深層心理を最重要視する
2. **プロンプトのカスタマイズ** — 目的／前提・制約／出力形式／不確実性の扱いの4要素を明示する
3. **AIに自己添削させる** — 誤字脱字・論理矛盾・読みにくい長文をAI自身にチェックさせてから貼り付ける
4. **人間の目で推敲する** — AI特有の構文癖（「〇〇ではない。〇〇だ」の連発）や言語混入に注意し、1文60文字以内に整える
5. **公開＆Xで拡散する** — 「書きました」ではなく熱量を込めて伝える。ただし本人の絶対軸に反する煽りは使わない

## 続ける仕組み（自動販売機化）

- 記事に定期的なアップデートを追記し、価値を落とさない
- ベイビーステップ：「毎日アプリを開くだけ」など、脳が抵抗を感じないレベルまでハードルを下げる
- 第三者の力：仲間と「やること宣言」をし、報告し合う
- 失敗の許容：一度できなかった日があっても、翌日から淡々と再開する。失敗は計画のうち
- セルフコンパッション：失敗した時、「自分自身」と「出来事」を切り離して考える
- 見逃すことへの恐怖：独自性のある発信で「見逃すと損」と感じさせる
- 最低半年の継続：結果がすぐ出なくても、半年間は発信を続ける覚悟を持つ
