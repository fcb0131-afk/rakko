# パクれるnote構成テンプレート（PASONAの法則）

出典：`らっこ_2_50代初心者/最高日給"37,719,700円"を叩き出した「パクれるnote構成テンプレート」.pdf`（全22スライド）

PASONAの法則は、セールスライティングで広く使われる型。この特典では note の無料エリア構成にこの型を当てはめる方法を解説している。

**重要**：この型自体（読者の悩みに寄り添い、解決策を示し、行動を促す、という骨格）は中立的で有用。ただし、原本にある具体的な文例には、本人の「人を傷つけない・意見を押し付けない」という絶対軸に反する煽り・恐怖訴求・誇張表現が含まれる。**該当箇所は「要フィルター」と明記し、book-guardianが自動的に穏やかな表現へ言い換える。**

## P：Problem（問題）
「note を読む人が抱える悩みや欲求を示す段階」。このページが自分にとって有益か判断する時間は3秒と言われる。ユーザーの興味あるキーワードや心に響くフレーズで、最初に読者が抱えている問題を明確にする。

→ そのまま使ってよい。読者の悩みを言い当てる、という部分に恐怖訴求は不要。

## A：Affinity（親近感）
「ユーザーの共感を誘い、商品の話をすんなり受け入れてもらう段階」。ストーリーや体験談を交えて具体的に執筆する。家族や知人友人の口コミが購買の決め手になることが多いのと同じで、共感を誘い仲良くなるためのステップ。

→ そのまま使ってよい。「自分が実際にやってみた記録を共有する」という本人のスタイルと相性が良い。

## S：Solution（解決策）
原本の例文：「今なら先着100名様だけ特別価格で提供します」「この機会を逃すとセミナー視聴権利を無くしてしまいます」→ **要フィルター**（限定感・損失回避の煽り）。原本は「お客様の声と損失回避効果を使うといい」と明記しているが、損失回避を煽る表現は使わない。

→ **使う場合**：解決策の中身を誠実に説明する部分のみ採用。「お客様の声（感想）を紹介する」のは中立的なので使ってよいが、「もっと早く使っておけばよかった」のような後悔を煽る誇張は避ける。

## O：Offer（提案）
商品・特典の内容を提示する段階。原本には価格の見せ方・特典の訴求例が含まれる。

→ 本編にある「リフレーミング」（価格の見方を変える、例：本1冊分）は中立的で使ってよい。誇大な特典訴求（「豪華特典」「独占公開」等のバズワード）は`buzzwords_filtered.md`のフィルターに従う。

## N：Narrow down（絞り込み）
ターゲットを絞り込み、「自分にこそ必要だ」と思わせる段階。本編の「オススメする人・しない人」に相当。

→ そのまま使ってよい。デメリット訴求（向いていない人を正直に伝える）は誠実さの表現であり、本人の軸とも合致する。

## A：Action（行動）
具体的な行動（購入・問い合わせ）を促す段階。

→ **要フィルター**：「今すぐ買わないと損」のような煽りは使わない。「読んでみて感じたことがあれば教えてください」程度の、押し付けない呼びかけに置き換える。

---

## このプロジェクトでの適用
8/12〜8/16のスプリントで note 記事の無料エリアを作る際（Phase2〜3）、P→A→S→O→N→Aの骨格は使うが、S（Solution）とA（Action）の煽り表現は必ずフィルターを通す。本編の「無料エリアの黄金テンプレート」（`main_book_principles.md`参照）とほぼ同じ骨格なので、実質的には本編の型にPASONAの見出し構造を足しただけ、という理解でよい。
